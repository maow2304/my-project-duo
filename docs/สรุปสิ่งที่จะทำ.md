# สรุปสิ่งที่จะทำ — UP Cloth Market

> เว็บซื้อขายเสื้อผ้าสำหรับนิสิตมหาวิทยาลัยพะเยา — กลุ่ม "ไม่ใส่กุ้ง" (รายวิชา 227202)

## เทคโนโลยี
- **Frontend**: Vue 3 + Vite + Vue Router + Pinia
- **UI**: Tailwind CSS v4 + Font Anuphan (Responsive)
- **Backend/DB**: Supabase — PostgreSQL, Auth, Storage, Realtime
- **โปรเจค Supabase**: `https://yneuoeyuvxfemavsrpci.supabase.co`
- ผู้ใช้แยก 2 บทบาท: **ผู้ซื้อ (Buyer)** / **ผู้ขาย (Seller)** — หน้าตาแยกกัน

## ฐานข้อมูล (PostgreSQL แปลงจาก MySQL ตาม ER)
- `buyer`, `seller` (uuid อ้างอิง auth.users), `product`, `cart`, `cart_item`, `orders`, `order_item`
- เพิ่ม: `conversations`, `messages` (แชท), `notifications` (แจ้งเตือน)
- RLS Policies + Seed ข้อมูลตัวอย่าง

## หน้าจอหลัก
**ฝั่งผู้ซื้อ** — ธีมร้านค้า
- หน้าแรก/รายการสินค้า + ค้นหา/กรอง, หน้ารายละเอียดสินค้า
- ตะกร้า, ยืนยันสั่งซื้อ, ประวัติออเดอร์+สถานะ
- แชทกับผู้ขาย, แจ้งเตือน, โปรไฟล์

**ฝั่งผู้ขาย** — ธีม Dashboard (sidebar)
- Dashboard (สินค้า/ออเดอร์/ยอดขาย)
- จัดการสินค้า CRUD + อัปรูป
- จัดการออเดอร์ + เปลี่ยนสถานะ
- แชทกับผู้ซื้อ, แจ้งเตือน, โปรไฟล์

**Auth**: สมัครเลือกบทบาท / ล็อกอิน / route guard แยกสิทธิ์

## ระบบเพิ่มเติม
- แชท Realtime (เปิดห้องจากหน้าสินค้า)
- แจ้งเตือน Realtime — สั่งซื้อ→แจ้งผู้ขาย, เปลี่ยนสถานะ→แจ้งผู้ซื้อ
- RLS กันข้อมูลรั่วเฉพาะของตนเอง
