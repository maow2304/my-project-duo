## ภาพรวมโครงการ

พัฒนาเว็บซื้อขายเสื้อผ้าสำหรับนิสิตมหาวิทยาลัยพะเยา มีผู้ใช้ 2 ประเภทคือ **ผู้ซื้อ (Buyer)** และ **ผู้ขาย (Seller)** โดยหน้าตาฝั่งผู้ซื้อและผู้ขายแยกกันอย่างชัดเจน

**เทคโนโลยีที่ใช้**
| ส่วน | เทคโนโลยี |
|---|---|
| Frontend | Vue 3 + Vite + Vue Router + Pinia |
| UI | Tailwind CSS v4 + Google Font (Anuphan) — Responsive Design |
| Backend | Supabase (PostgreSQL + Auth + Storage + Realtime) |
| Database | PostgreSQL บน Supabase |
| Auth | Supabase Auth (email/password) + ระบุบทบาทผ่านตาราง buyer/seller |

**Supabase project**: `https://yneuoeyuvxfemavsrpci.supabase.co` (anon key พร้อมใช้)

## แผนแบ่งเป็น 8 เฟส

### เฟส 0 — ตั้งค่า Supabase และฐานข้อมูล (ก่อนเริ่มโค้ด)

**เป้าหมาย**: ฐานข้อมูลปลอดภัยพร้อมใช้งาน

- [ ] 0.1 เขียน schema PostgreSQL (แปลงจาก MySQL ตาม ER) — ตาราง `buyer`, `seller`, `product`, `cart`, `cart_item`, `orders`, `order_item` + ตารางเพิ่มเติม `conversations`, `messages`, `notifications`
- [ ] 0.2 Seed ข้อมูลตัวอย่าง — seller 5 ราย, buyer 5 ราย, สินค้า 5 รายการ
- [ ] 0.3 RLS Policies ทุกตาราง — ผู้ซื้อ/ผู้ขายเข้าถึงได้เฉพาะข้อมูลของตนเอง
- [ ] 0.4 เปิด Realtime สำหรับ `messages` และ `notifications`
- [ ] 0.5 สร้าง Storage bucket `product-images` (public) สำหรับรูปสินค้า

**ผลลัพธ์**: DB + RLS + Realtime + Storage พร้อมใช้
